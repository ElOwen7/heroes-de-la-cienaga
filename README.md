# Héroes de la Ciénaga de la Virgen — Demo

Juego educativo estático construido en HTML, CSS y JavaScript.

## Despliegue en Render

1. Sube `public/` y `render.yaml` a un repositorio de GitHub.
2. En Render selecciona **New > Static Site** y conecta tu repositorio.
3. Configura **Build Command:** `echo "Sitio estatico listo"` y **Publish Directory:** `public`.
4. Publica el sitio.

No requiere Node.js ni servidor de aplicación. El archivo principal es `public/index.html`.
